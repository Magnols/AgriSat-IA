# Frontend AgriSat IA

Protótipo navegável em HTML, CSS e JavaScript. As telas demonstram acompanhamento agrícola, mapas, alertas e recomendações com dados simulados.

Login, Google, recuperação de senha, satélites, IA e SMS são elementos demonstrativos, não serviços implementados. O formulário de login apenas muda a tela; não autentica usuários. O frontend ainda não consome a API Spring Boot.

Arquivos: index.html, style.css, script.js e logo.png. No Compose, Nginx serve esta pasta em http://localhost:8081. Também é possível abrir index.html diretamente para demonstração.

A cópia estática na raiz foi preservada para compatibilidade com os caminhos da hospedagem anterior. Não foi consolidada sem validar a configuração remota.

## Avisos existentes

Este projeto é de uso acadêmico e educacional.
